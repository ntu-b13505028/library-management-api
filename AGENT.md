\# AGENTS.md



\## Project

This project is the Spring Boot backend for the library management system.

Do not modify the old Swing project.



\## Working rules

\- Work only inside library-management-api

\- Keep the code beginner-friendly

\- Use plain Spring Boot + JDBC for now

\- Do not introduce JPA unless explicitly requested

\- Do not add Spring Security yet unless explicitly requested

\- Do not redesign the whole architecture at once

\- Make small, safe changes

\- Explain clearly which files were created or modified



\## Current goal

We are gradually converting the existing local Java Swing library system into a web backend.

Start with simple REST APIs such as:

\- /hello

\- /api/books

\- /api/login

\- /api/register



\## Database

Use the existing MySQL database:

\- database name: library\_system



\## Notes

\- Keep API outputs simple and easy to test in browser/Postman

\- Prefer step-by-step implementation
